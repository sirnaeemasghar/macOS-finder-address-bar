# Changelog

## 1.2.0 — 2026-10-07 (development preview)

- Removed the refresh and recent-locations toolbar buttons; retained F5 refresh, F4 history, Down Arrow suggestions, and the Terminal button.
- Preserved button spacing, path layout, toolbar placement, sizing, and folder tracking.
- Resolved layer colors under the view’s effective appearance to fix the white editing background in dark mode.
- Added a softer, 3-point external focus border and light/dark fills based on Finder search-field reference screenshots.
- Used the same interior fill for viewing and editing in each theme.
- Removed the drop shadow for a flatter toolbar appearance.
- Updated installation, upgrade, and keyboard-access documentation.

## 1.0.1 — 2026-09-29 (development preview)

- Fixed full-screen address bar placement and toolbar tracking.
- Matched Finder toolbar control height and restored a soft shadow.
- Added a frosted background to obscure the underlying folder title.
- Improved native typography and vertically centered editable path text.
- Synchronized folder and editing state when switching Finder windows.
- Expanded automated coverage to 57 checks.

## 1.0 — Initial development preview

- Native Apple Silicon Finder address-bar companion.
- Adaptive toolbar placement using Accessibility geometry.
- Pill-shaped transparent click-to-edit field and clickable breadcrumbs.
- Folder suggestions, recent locations, aliases, and context-menu actions.
- Terminal opening in the current Finder folder.
- File/app/URL opening, parent navigation, refresh, and new Finder windows.
- Finder-managed breadcrumb drag/drop transfers.
- Login registration and local placement diagnostics.
- Automated path, quoting, history, and geometry checks.

No stable or notarized release has been published.
